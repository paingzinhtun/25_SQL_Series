Welcome to the **25 SQL Projects Series**! This repository is a carefully curated collection of 25 hands-on SQL projects designed to elevate your database skills from foundational queries to complex data warehouse architectures and ETL pipelines.

Whether you are a beginner looking to understand basic database design or an aspiring Data Engineer/Analyst aiming to build real-world data solutions, this series provides a structured path to mastery.

---

## 🌟 What's Inside?

Each project in this series represents a real-world scenario and comes fully equipped with:
- **`schema.sql`**: DDL scripts to create tables, keys, and constraints.
- **`insert_data.sql`**: DML scripts to populate the database with realistic sample data.
- **`business_questions.md`**: Real-world business problems that need solving.
- **`analysis_queries.sql`**: The SQL solutions to the business questions, showcasing various techniques.
- **`README.md`**: A project-specific guide explaining the context, goals, and setup.

*Advanced projects also include Python scripts, ETL simulations, and data warehousing concepts.*

## 🛠️ Prerequisites

To get the most out of this repository, you will need:
- A relational database management system (RDBMS) like **PostgreSQL** (recommended), **MySQL**, or **SQL Server**.
- A SQL IDE or client (e.g., pgAdmin, DBeaver, DataGrip, or VS Code with SQL extensions).
- Python 3.x (Required only for the final Data Engineering projects).

## 🚀 How to Use This Repository

1. **Clone the repo:**
   ```bash
   git clone https://github.com/yourusername/25_SQL_Series.git
   cd 25_SQL_Series
   ```
2. **Pick a project:** Start from `01` if you are a beginner, or jump into any specific topic that interests you.
3. **Set up the Database:** Run `schema.sql` to create the tables, followed by `insert_data.sql` to load the data.
4. **Solve the Problems:** Read `business_questions.md` and try writing the SQL queries yourself.
5. **Check your Answers:** Compare your solutions with `analysis_queries.sql`.

## 📚 Key Concepts Covered

Throughout these 25 projects, you will learn and apply:
- **DDL & DML operations** (CREATE, ALTER, INSERT, UPDATE, DELETE)
- **Advanced Joins & Set Operations**
- **Window Functions** (`ROW_NUMBER()`, `RANK()`, `LEAD()`, `LAG()`, `SUM() OVER()`)
- **Common Table Expressions (CTEs) & Recursive CTEs**
- **Data Warehousing Concepts** (Star Schema, Fact & Dimension Tables)
- **Slowly Changing Dimensions (SCD Type 1 & 2)**
- **ETL/ELT Pipelines**
- **Query Optimization & Performance Tuning**
